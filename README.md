# Kartik Grewal Portfolio

Static portfolio based on the provided reference design.

## Publish on GitHub Pages

1. Upload the repository files to the `main` branch.
2. In repository Settings → Pages, select `Deploy from a branch`, choose `main` and `/ (root)`, then save.
3. The site URL will be `https://kartikgrewal152.github.io/Portfolio/` after Pages finishes deploying.

The CV and certificate buttons point to the supplied Google Drive files. Those files must be shared as “Anyone with the link can view” for visitors to open them.

The contact form currently opens a prefilled message in the visitor’s default email app. For direct in-page submission, create a Formspree form, verify the account email, and replace the `mailto:` form handler with the form endpoint. Do not reuse the reference portfolio owner’s endpoint.
